# 轻量故障恢复

仅在工具、代理启动、状态或等待异常时读取。代码和测试失败按 `SKILL.md` 的开发反馈处理。

- 参数、模型、权限、路径或输入错误：修正原因后才能继续；不可修正则停止，不原样重试。
- 超时、连接中断或临时服务异常：同一操作最多一次改变策略的重试。
- 等待超时：只读取一次代理状态；无实质进展则停止自动轮询。
- 代理失败：保留其他结果，停止失败分支，不自动创建替代代理链。

主代理集中记录工具恢复，整轮最多两次。达到预算后停止新代理和新的业务工具调用，但仍可进行一次必要的状态读取、中断、所有权释放和非破坏性清理。

报告已完成内容、原始错误、是否重试、未完成范围和下一步。只有用户明确要求后才开始新一轮。
